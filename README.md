# 🛒 DMart Sales Analytics Dashboard

## 📌 Overview

The DMart Sales Analytics Dashboard is an interactive web dashboard developed to analyze sales performance using CSV data. It provides business insights through KPI cards, interactive charts, filters, search functionality, and an India store map.

---

## 🚀 Features

- 📊 Live KPI Cards
- 📈 8 Interactive Charts
- 🔍 Search Functionality
- 🎯 Multi-Level Filters
- 📄 CSV File Upload
- 🗺️ India Store Presence Map
- 📱 Responsive Design
- ✨ Animated Dashboard
- 📋 Dynamic Data Table

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Chart.js
- CSV Dataset

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

**Recommended (VS Code):**
1. Open the project in Visual Studio Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Click **Open with Live Server**.

The dashboard will open in your browser and load the DMart Sales Analytics Dashboard.

> **Note:** Make sure the `data` and `assets` folders remain in the project directory. If you move or rename them, some features (such as the CSV data or India map) may not work correctly.
